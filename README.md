# tidal-addon

Local ha-apps add-on repository — offers **Tidal (Mopidy)**, a Tidal
streaming client that plays through the host's sound card, in the
[homeassistant-apps](https://github.com/rubo77/homeassistant-apps) store.

Deploy: the store scans `HA_APPS_LOCAL_REPO` (default
`/var/lib/ha_apps/local`) — sync this folder's `tidal/` directory there.
